Antworten auf die häufigsten Fragen rund um Silverline.

Wo sind meine Daten gespeichert?

Lokal auf deinem Gerät, in der Browser-Datenbank. Sie werden nicht automatisch an einen Server gesendet – nur wenn du dich anmeldest und aktiv synchronisierst.

Wo stehen die Server für die Synchronisation?

Gemäss aktuellem Hosting-Setup werden synchronisierte Daten auf Servern in der Schweiz (Infomaniak) gespeichert.

Kann ich die App auf mehreren Geräten nutzen?

Ja. Erstelle ein Konto, erfasse deine Daten auf einem Gerät und synchronisiere. Melde dich auf dem anderen Gerät an und tippe auf Sync – du hast dieselben Daten.

Muss ich ein Konto erstellen?

Nein. Silverline funktioniert vollständig ohne Anmeldung. Ein Konto ist nur nötig, wenn du deine Daten auf dem Server sichern oder zwischen Geräten synchronisieren möchtest.

Wie lösche ich meine Daten?

Öffne die Einstellungen deines Browsers und lösche die Website-Daten für mysilverline.it-pin.ch. Damit werden alle lokal gespeicherten Daten entfernt.

Muss ich die App aktualisieren?

Nein. Silverline aktualisiert sich automatisch im Hintergrund, wenn du online bist. Du hast immer die neueste Version – ohne manuelles Update.

Was passiert bei einem Vorlagen-Wechsel?

Deine bestehenden Daten werden überschrieben. Du wirst vorher gefragt, ob du fortfahren möchtest. Tipp: Synchronisiere vorher, um eine Sicherung auf dem Server zu haben.

Funktioniert die App auch ohne Internet?

Ja, vollständig. Du kannst Daten erfassen, die Bilanz anschauen und den Forecast berechnen – alles offline. Nur die Synchronisation mit dem Server braucht eine Internetverbindung.

Welche Browser werden unterstützt?

Silverline funktioniert in allen modernen Browsern: Chrome, Edge, Safari, Samsung Internet und Firefox. Die PWA-Installation funktioniert am besten in Chrome (Desktop + Android) und Safari (iOS).
