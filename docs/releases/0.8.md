# Silverline Release 0.8

Release-Datum: 2026-02-25

## Highlights

- Forecast erweitert: Liquiditaet ist als zweite Linie sichtbar, inkl. Warnungsbezug auf die Liquiditaetslinie.
- Basis-Form auf konsistentes Autosave-Verhalten umgestellt (ohne separaten Speichern-Button).
- Synchronisationsverhalten beim Login abgesichert: Login fuehrt nur Pull aus, kein automatischer Push.
- Musterfall-Vorlagen verbessert: "Familie 30+" mit bewusstem Liquiditaetsengpass in 2029, Horizonte bis Alter 80.
- Konsistente Ansprache in Du-Form in App- und Doku-Texten.

## Functional Changes

### Forecast und Analyse

- Zweite Linie fuer Liquiditaet in der Forecast-Chart-Ansicht.
- Kennzahl "Delta Liquiditaet im Zeitraum" als kompakte KPI im Chart-Header.
- Forecast-Detailanzeige: Startjahr-Darstellung korrigiert.

### Datenbearbeitung und UX

- Basis-Bereich nutzt jetzt onDirty/Autosave analog zu den restlichen Formularbereichen.
- User-Logout zeigt einen Hinweis, wenn lokale Aenderungen noch nicht synchronisiert wurden.

### Sync und Datenkonsistenz

- `runSync` unterstuetzt jetzt Push-Steuerung (`push: false` fuer Login-Flow).
- Login triggert nur Pull, damit lokale Zwischenstaende nicht ungewuenscht auf den Server geschrieben werden.

### Musterfaelle

- Template "Familie 30+":
  - Jahresausgaben auf 110'000 CHF gesetzt.
  - zusaetzlicher Einmal-Event 2029 fuer gezielten Liquiditaetsengpass.
- Alle Standard-Templates laufen bis Alter 80 (dynamisch aus Geburtsjahr berechnet).

### Terminologie und Content

- Begrifflichkeit vereinheitlicht: "Vermoegen" und "Schulden" statt gemischter Bezeichnungen.
- Du-Form in App-/Web-Doku weiter harmonisiert.
- Beta-Einladung um konkreten Testauftrag erweitert.

## Technik

- Build/Deploy-Prozess unveraendert, Release ist produktiv deployed.
- Keine bekannten Breaking Changes fuer bestehende Nutzerdaten.
