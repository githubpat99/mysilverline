# Silverline Video Docs

Dieses Verzeichnis enthält die inhaltliche Planung für Silverline-Info-Videos.

## Struktur

- `STORYLINE_V1.md` - Hauptstoryline (Version 1)
- `episodes/` - Einzelskripte pro Video
- `shotlists/` - Szenenlisten und Aufnahmeplanung
- `assets/` - Referenzen (Logos, Screenshot-Links, Musikhinweise)

## Empfehlung

- Rohvideos (`.mp4`, `.mov`) nicht ins Repo committen.
- Stattdessen externe Ablage nutzen (OneDrive/Drive/Dropbox) und Links hier dokumentieren.
