# Silverline Release Notes

Dieses Verzeichnis enthaelt die fortlaufenden Release Notes.

## Versionierungs-Logik

- Minor Releases (`0.8`, `0.9`, `1.1`, `1.2`): jeweils eigene Datei mit den konkreten Aenderungen.
- Major Releases (`1.0`, `2.0`, ...): eigene Summary-Datei mit:
  - den wichtigsten Highlights auf hohem Niveau
  - Migrations-/Betriebshinweisen (falls noetig)
  - Verweisen auf die enthaltenen Minor Release Notes

## Dateinamensschema

- Minor: `0.8.md`, `0.9.md`, `1.1.md`
- Major Summary: `1.0-summary.md`, `2.0-summary.md`
